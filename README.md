# Easy Record

A modern, web-based record management system built with React + Node.js + PostgreSQL (Neon).

## Project Structure

```
Easy Record/
├── web/          # React frontend (Vite + TypeScript)
├── server/       # Node.js backend (Express + PostgreSQL)
└── README.md
```

## Getting Started

### Prerequisites
- Node.js 18+
- npm

### Backend Setup
```bash
cd server
npm install
npm run dev
```

### Frontend Setup
```bash
cd web
npm install
npm run dev
```

## Tech Stack
- **Frontend**: React 19, TypeScript, Vite
- **Backend**: Node.js, Express
- **Database**: PostgreSQL (Neon)
